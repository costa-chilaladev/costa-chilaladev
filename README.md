# 👨🏾‍💻 Costa Chilala

**`Full-Stack Web & Desktop Developer`**

My name is Costa Chilala, I'm from Luanda, Angola. I'm a developer focused on building web and desktop applications, with a strong interest in backend development and modern web interfaces.

I work with technologies like **HTML, CSS, JavaScript, TypeScript, PHP, React, Node.js, and Tailwind CSS**, and I'm currently expanding my knowledge of **Rust and PostgreSQL**.

Some of my projects include **CookTogether**, a social platform for sharing and discovering recipes, and **Kora**, a desktop tool for simplifying project setup and development workflows.
